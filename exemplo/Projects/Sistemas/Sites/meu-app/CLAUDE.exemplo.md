## O diário é obrigatório

`DIARIO.md` é o registro completo do que foi feito no projeto, escrito para quem
está aprendendo a programar. **Ao fim de cada sessão de trabalho, acrescente uma
entrada nova antes de encerrar** — o que foi pedido, o que foi feito, por quê, os
problemas encontrados, e como sabemos que funcionou. Explique os termos técnicos
na primeira vez que aparecerem.

Não é um resumo curto: é para o dono do projeto conseguir entender cada parte do
que foi construído, lendo depois, sozinho. Errar para o lado do detalhe.
